## Name & Idee
- **Name:** UIPrism (Schreibweise: „UI" ink, „Prism" indigo)
- **Tagline:** *Map your UI, automatically.*
- **Metapher:** Ein Prisma nimmt diffuses Licht und zerlegt es in ein klares Spektrum — UIPrism nimmt gewachsene, wirre UI und zerlegt sie in ein sauberes, systematisches Designsystem. Das Spektrum ist das Marken-Signal.

## Logo
- Datei: `uiprism-logo.svg` (Prisma + eingehender Strahl → aufgefächertes Spektrum + Wortmarke).
- Icon-only möglich (nur Prisma + Spektrum) für kleine Flächen/Favicon.
- Auf dunklen Slides: Wortmarke in Weiß, Spektrum bleibt farbig.

**Regel:** Indigo trägt die Marke. Das volle Spektrum wird **sparsam** eingesetzt (Logo, eine feine Trennlinie, evtl. Progress-Dots) — nie flächig, damit es edel bleibt.

## Typografie
- Eine Grotesk (Inter / System-Stack). Headline Bold (800), Body Regular.
- Enges Tracking auf großen Headlines.

## Anwendung

> **Scope-Regel (verbindlich, 20.07.):** Das Branding gilt für **Marketing/Öffentlichkeit** — Deck, One-Pager, Außenauftritt. **App und Plugin bleiben bewusst minimal** und im bestehenden, reduzierten Look. Dort **kein** flächiges Umbranden (keine indigo Buttons/Nav/Spektrum). Sichtbare Marke in der App/im Plugin nur an genau einer Stelle: **Logo/Wortmarke im Header**. Ein evtl. späterer Startscreen/Splash darf mehr Marke tragen — die Arbeitsansicht nicht.

- **Deck:** Logo auf Titel- und Schluss-Slide; Indigo als Akzent; eine Slide-Kategorie darf eine dünne Spektrum-Linie als Signatur tragen.
- **One-Pager:** Logo oben, Indigo-Akzent, Spektrum als feine Linie unter dem Titel.
- **App:** so minimal wie bisher lassen. **Nur** Header-Logo/Wortmarke „Designbridge" → UIPrism tauschen (+ Tab-Titel/Favicon). Bestehende UI-Farben/Buttons unangetastet. Header-Logo-Ausgestaltung noch offen (gefällt Rob so noch nicht → separater Design-Schritt mit Briefing).
- **Plugin:** ebenfalls minimal — Name/Logo an einer Stelle, sonst kein Brand-Layer.
