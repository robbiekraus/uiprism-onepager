Turn UI sources into design-system components.

UIPrism reads a screenshot, breaks it into design tokens and components, maps them to shadcn/ui, and writes the result to Figma and Storybook.

Open the prototype Watch the walkthrough

Started as a bootcamp prototype. Tested with other designers. Development continues as a beta.

The problem

Source material arrives in every shape. Translating it is manual work.

Every shape

Wireframes from stakeholders, screenshots of existing features, whole pages from running software, or just a URL.

Rebuilt by hand

Someone translates each source into design-system components, element by element. Each rebuild drifts a little from the last.

Drift without a signal

Design file and code move apart quietly. The gap shows up late, when it is expensive to close.

The gap kept coming up across teams, most recently at a cost-management platform for the construction industry that had its own software and no design system.

How it works

One pipeline from source to system.

01 · READ

Break the source down

The AI extracts design tokens (colors, typography, spacing, radius, shadows) and detects UI components, grouped as atoms, molecules, organisms and templates. Every value carries a confidence level.

02 · MATCH

Map to a design system

Each detected component is resolved against a component catalog instead of being redrawn freehand. Today that catalog is shadcn/ui with Tailwind.

Figma components and code components then share one vocabulary. Using your own repository as the catalog is the next step.

→
03 · WRITE

Write it where teams work

Figma: components, text styles and color styles, written by the UIPrism plugin.

Code: JSX components and a tokens.css file to download.

Storybook: a live preview with all detected components, their variants and controls.

Every value carries a confidence level.

Extracted colors, type sizes and spacing values are labeled High, Medium or Low. Reviewers see what to check first instead of auditing everything.

Status · Beta

What works today, and what does not yet.

Available

  • Screenshot import with token extraction
  • Component detection: atoms, molecules, organisms, templates
  • Mapping to shadcn/ui components
  • Figma export via plugin: components, text styles, color styles
  • Code download: JSX and tokens.css
  • Storybook preview

Preview

  • URL import
  • Repository import

Planned

  • Your own repository as the component catalog
  • Your own Figma design system as the component catalog

UIPrism is in beta. It started as a prototype in the Vibe Coding Bootcamp and has been tested with other designers. It is not in continuous use yet. Development continues.

Results are most reliable for single components. Full-page layouts are still being refined.
